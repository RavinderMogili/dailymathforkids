   - Choices: A) x = 1  B) x = 4  C) x = −4  D) y = 4
   - Hint: The vertical asymptote occurs where the denominator equals zero.
   - Steps:
     - Try f(x) = 1/(x − 7): set x − 7 = 0; x = 7. Vertical asymptote: x = 7.
     - For f(x) = 1/(x − 4): set x − 4 = 0; x = 4.
     - So the result is x = 4.
   - Answer: x = 4

9. **[Hard] Binomial Theorem**
   - EN: In the expansion of (x + 2)⁴, what is the coefficient of x²?
   - FR: Dans le développement de (x + 2)⁴, quel est le coefficient de x²?
   - Choices: A) 16  B) 24  C) 12  D) 8
   - Hint: Use the binomial theorem: the term with x² is C(4,2) × x² × 2².
   - Steps:
     - Try (x + 3)³: the x¹ term is C(3,1) × x × 3² = 3 × 9x = 27x.
     - For (x + 2)⁴: x² term = C(4,2) × x² × 2² = 6 × x² × 4 = 24x².
     - The coefficient is 24.
     - So the result is 24.
   - Answer: 24

10. **[Hard] Derivative — Optimization**
    - EN: The profit function for a school fundraiser is P(x) = −x² + 8x − 12, where x is the number of items sold. How many items should be sold to maximize profit?
    - FR: La fonction de profit d'une levée de fonds scolaire est P(x) = −x² + 8x − 12, où x est le nombre d'articles vendus. Combien d'articles faut-il vendre pour maximiser le profit?
    - Choices: A) x = 4 items  B) x = 6 items  C) x = 8 items  D) x = 3 items
    - Hint: Take the derivative, set it equal to zero, and solve for x.
    - Steps:
      - Try P(x) = −x² + 6x − 5: P′(x) = −2x + 6; set to 0: x = 3.
      - For P(x) = −x² + 8x − 12: P′(x) = −2x + 8; set to 0: −2x + 8 = 0; 2x = 8; x = 4.
      - So the result is x = 4 items.
    - Answer: x = 4 items
