   - EN: Solve f(x) = x³ - 1 for x.
   - FR: Résous f(x) = x³ - 1 pour x.
   - Choices: A) x = 1  B) x = 0  C) x = 2  D) x = -1
   - Hint: Find the root by setting f(x) = 0.
   - Steps:
     - x³ - 1 = 0.
     - x³ = 1.
     - x = 1.
   - Answer: A) x = 1

2. **[Easy] Basics of Derivatives**
   - EN: Find the derivative of f(x) = 3x².
   - FR: Trouvez la dérivée de f(x) = 3x².
   - Choices: A) 6x  B) 3x  C) 4x  D) 2x
   - Hint: Differentiate power rule.
   - Steps:
     - Derivative: f'(x) = 6x.
   - Answer: A) 6x

3. **[Easy] Combinations Intro**
   - EN: Find the number of combinations: Choose 2 from 5.
   - FR: Trouvez le nombre de combinaisons : choisir 2 parmi 5.
   - Choices: A) 10  B) 5  C) 15  D) 20
   - Hint: Use Combination formula nCr = n!/(r!(n-r)!).
   - Steps:
     - Calculation: 5!/(2!3!) = 10.
   - Answer: A) 10

4. **[Easy] Vectors Applied**
   - EN: If A = 3i + 2j and B = i - j, find A + B.
   - FR: Si A = 3i + 2j et B = i - j, trouvez A + B.
   - Choices: A) 4i + j  B) 2i + 3j  C) 6i + j  D) 5i + j
   - Hint: Combine i and j components separately.
   - Steps:
     - A + B = (3i + i) + (2j - j).
     - Result: 4i + j.
   - Answer: A) 4i + j

5. **[Medium] Rational Functions**
   - EN: Identify the vertical asymptote of f(x) = 1/(x - 2).
   - FR: Identifiez l'asymptote verticale de f(x) = 1/(x - 2).
   - Choices: A) x = 2  B) y = 2  C) x = -2  D) y = -2
   - Hint: Denominator where undefined.
   - Steps:
     - Asymptote occurs where x - 2 = 0.
     - Solve: x = 2.
   - Answer: A) x = 2

6. **[Medium] Advanced Trigonometry**
   - EN: Solve for θ: tan(θ) = 1, find θ between 0° and 180°.
   - FR: Résolvez pour θ : tan(θ) = 1, trouvez θ entre 0° et 180°.
   - Choices: A) 45°  B) 90°  C) 135°  D) 180°
   - Hint: Tan equals 1 where sin = cos.
   - Steps:
     - Tan(θ) = 1 at 45° and 135°.
   - Answer: A) 45°

7. **[Medium] Functions and Domain**
   - EN: What's the domain of g(x) = √(x + 2)?
   - FR: Quel est le domaine de g(x) = √(x + 2)?
   - Choices: A) x ≥ -2  B) x ≤ -2  C) x ≠ 2  D) x > -2
   - Hint: Under root non-negative.
   - Steps:
     - x + 2 ≥ 0, x ≥ -2.
   - Answer: A) x ≥ -2

8. **[Medium] Probability Distributions**
   - EN: In a probability distribution with events A, B, C that must add to one, if P(A) = 0.2, P(B) = 0.5, find P(C).
   - FR: Dans une distribution probabiliste avec des événements A, B et C qui doivent s'additionner à un, si P(A) = 0,2, P(B) = 0,5, trouvez P(C).
   - Choices: A) 0.2  B) 0.5  C) 0.3  D) 0.4
   - Hint: Total probability must be 1.
   - Steps:
     - P(C) = 1 - (P(A) + P(B)).
     - P(C) = 1 - 0.7 = 0.3.
   - Answer: C) 0.3

9. **[Hard] Vector Magnitude**
   - EN: Find the magnitude of vector A = 3i + 4j.
   - FR: Trouvez la magnitude d'un vecteur A = 3i + 4j.
   - Choices: A) 5  B) 7  C) 4  D) 6
   - Hint: Use √(i² + j²).
   - Steps:
     - Magnitude = √(3² + 4²).
     - √(9 + 16) = √25 = 5.
   - Answer: A) 5
