   - FR: Une roulette a les résultats 1, 2, 3 et 4, tous également probables. Quelle est la valeur espérée?
   - Choices: A) 1.5  B) 2.0  C) 2.5  D) 3.0
   - Hint: Expected value = sum of (each value × its probability) (e.g., outcomes 1 and 3 each with prob. 1/2: E = 1×0.5 + 3×0.5 = 2).
   - Steps:
     - Each outcome has probability 1/4.
     - E = 1(1/4) + 2(1/4) + 3(1/4) + 4(1/4).
     - E = (1 + 2 + 3 + 4)/4 = 10/4 = 2.5.
   - Answer: 2.5

7. **[Medium] Vectors — Addition**
   - EN: Vector **a** = (3, 5) and vector **b** = (−1, 4). What is **a** + **b**?
   - FR: Le vecteur **a** = (3, 5) et le vecteur **b** = (−1, 4). Quelle est la valeur de **a** + **b**?
   - Choices: A) (2, 1)  B) (4, 9)  C) (2, 9)  D) (4, 1)
   - Hint: Add corresponding components (e.g., (2, 7) + (3, −1) = (2+3, 7+(−1)) = (5, 6)).
   - Steps:
     - x-component: 3 + (−1) = 2.
     - y-component: 5 + 4 = 9.
     - **a** + **b** = (2, 9).
   - Answer: (2, 9)

8. **[Medium] Rational Function — Vertical Asymptote**
   - EN: What is the vertical asymptote of f(x) = (x + 2) / (x − 5)?
   - FR: Quelle est l'asymptote verticale de f(x) = (x + 2) / (x − 5)?
   - Choices: A) x = −2  B) x = 2  C) x = 5  D) x = −5
   - Hint: Vertical asymptotes occur where the denominator equals zero (e.g., f(x) = 1/(x − 3) has vertical asymptote x = 3).
   - Steps:
     - Set the denominator equal to zero: x − 5 = 0.
     - x = 5.
     - Vertical asymptote is at x = 5.
   - Answer: x = 5

9. **[Hard] Binomial Theorem**
    - EN: What is the coefficient of x² in the expansion of (x + 3)⁴?
    - FR: Quel est le coefficient de x² dans le développement de (x + 3)⁴?
    - Choices: A) 54  B) 81  C) 108  D) 216
    - Hint: Use the binomial theorem: the term with x^k is C(n,k) × x^k × 3^(n−k); for x², k = 2 (e.g., (x + 2)³: x² term is C(3,2) × x² × 2¹ = 6x²).
    - Steps:
      - The x² term: C(4,2) × x² × 3^(4−2).
      - C(4,2) = 6; 3² = 9.
      - Coefficient = 6 × 9 = 54.
    - Answer: 54

10. **[Hard] Derivative Application — Optimisation**
    - EN: A farmer has 60 m of fencing to enclose a rectangular garden against a barn wall (the barn forms one side, so only 3 sides need fencing). What width (in metres) maximises the area?
    - FR: Un fermier a 60 m de clôture pour entourer un jardin rectangulaire contre un mur de grange (la grange forme un côté, donc seulement 3 côtés ont besoin de clôture). Quelle largeur (en mètres) maximise l'aire?
    - Choices: A) 10 m  B) 15 m  C) 20 m  D) 30 m
    - Hint: Write the area as a function of one variable, take the derivative, set it to zero and solve (e.g., fencing = 40 m, one long side free: L + 2W = 40, A = W(40 − 2W), A' = 40 − 4W = 0, W = 10).
    - Steps:
      - Let W = width. Then length L = 60 − 2W.
      - Area A = W(60 − 2W) = 60W − 2W².
      - A'(W) = 60 − 4W = 0 → W = 15 m.
    - Answer: 15 m
