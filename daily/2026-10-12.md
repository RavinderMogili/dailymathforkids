   - FR: Où se trouve l'asymptote verticale de la fonction f(x) = 1 / (x − 4)?
   - Choices: A) x = −4  B) x = 0  C) x = 1  D) x = 4
   - Hint: A vertical asymptote occurs where the denominator equals zero (e.g., f(x) = 1/(x + 3): denominator = 0 when x = −3).
   - Steps:
     - Set denominator to zero: x − 4 = 0.
     - x = 4.
     - So the vertical asymptote is x = 4.
   - Answer: x = 4

9. **[Hard] Permutations with Restrictions**
    - EN: How many 4-letter arrangements can be made from the letters A, B, C, D, E if the first letter must always be A?
    - FR: Combien d'arrangements de 4 lettres peut-on former avec les lettres A, B, C, D, E si la première lettre doit toujours être A?
    - Choices: A) 12  B) 24  C) 48  D) 60
    - Hint: Fix the restricted position, then count the remaining arrangements (e.g., 4 letters with first fixed: 1 × 3 × 2 × 1 = 6 ways for positions 2, 3, 4).
    - Steps:
      - First position: fixed as A (1 way).
      - Remaining 3 positions from 4 remaining letters: P(4, 3) = 4 × 3 × 2 = 24.
      - Total = 1 × 24 = 24.
    - Answer: 24

10. **[Hard] Derivative — Optimization**
    - EN: The profit function for a company is P(x) = −2x² + 40x − 50, where x is the number of items sold. How many items maximize the profit?
    - FR: La fonction de profit d'une entreprise est P(x) = −2x² + 40x − 50, où x est le nombre d'articles vendus. Combien d'articles maximisent le profit?
    - Choices: A) x = 8  B) x = 10  C) x = 12  D) x = 20
    - Hint: Find the derivative, set it equal to zero, and solve for x (e.g., P(x) = −3x² + 12x → P'(x) = −6x + 12 = 0 → x = 2).
    - Steps:
      - P'(x) = −4x + 40.
      - Set equal to zero: −4x + 40 = 0.
      - 4x = 40 → x = 10.
      - So 10 items maximize the profit.
    - Answer: x = 10
