    - Choices: A) 80 m²  B) 90 m²  C) 100 m²  D) 120 m²
    - Hint: For a fixed perimeter, the area is maximised when the shape is a square — set up A = l × w with 2l + 2w = 40, substitute, differentiate and set A'(l) = 0.
    - Steps:
      - Perimeter: 2l + 2w = 40, so l + w = 20, meaning w = 20 − l.
      - Area: A = l(20 − l) = 20l − l². Differentiate: A'(l) = 20 − 2l = 0, so l = 10.
      - w = 10; maximum area = 10 × 10 = 100 m².
    - Answer: 100 m²
