    - Choices: A) 30°  B) 90°  C) 60°  D) 45°
    - Hint: Dot product: u·v = u₁v₁ + u₂v₂. Magnitudes: |u| = √(u₁²+u₂²). Then find the angle using inverse cosine.
    - Steps:
      - u·v = (1)(1) + (0)(1) = 1.
      - |u| = √(1+0) = 1; |v| = √(1+1) = √2.
      - cos θ = 1/(1 × √2) = 1/√2; θ = cos⁻¹(1/√2) = 45°.
