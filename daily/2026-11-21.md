   - EN: Find the derivative of f(x) = (2x + 1)^3.

   - Steps:
     - Step 1: Let u = 2x + 1, so f(u) = u³.

6. **[Medium] Product Rule Derivative**
   - EN: Find the derivative of f(x) = (x² + 3x)(x + 1).

   - Choices: A) 3x² + 8x + 3  B) 3x² + 8x + 2  C) 3x² + 7x + 3  D) 3x² + 7x + 2
   - Hint: Use the product rule: f'(x) = u’v + uv’.
   - Steps:
     - Step 1: Let u = x² + 3x, v = x + 1.
     - Step 2: u’ = 2x + 3, v’ = 1.
     - Step 3: Compute u’v = (2x + 3)(x + 1) = 2x² + 5x + 3, uv’ = (x² + 3x)(1) = x² + 3x.
     - Step 4: Add: 2x² + 5x + 3 + x² + 3x = 3x² + 8x + 3.
   - Answer: 3x² + 8x + 3
