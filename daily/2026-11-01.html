  5. [Medium] Rational Functions

    • EN: What is the vertical asymptote of ( f(x) = \frac{1}{x-3} )?
    • FR: Quelle est l'asymptote verticale de ( f(x) = \frac{1}{x-3} )?
    • Choices: A) x = 0 B) x = 3 C) x = -3 D) y = 3
    • Hint: The vertical asymptote is where the denominator is zero.
    • Steps:
      • Set ( x - 3 = 0 )
      • Solve for x: ( x = 3 )
    • Answer: x = 3
