   - Choices: A) x + 2  B) x + 3  C) x + 4  D) x² + 3
   - Hint: Factor the numerator and cancel the common factor (e.g., (x² + 7x + 12) ÷ (x + 3) = (x + 3)(x + 4) ÷ (x + 3) = x + 4).
   - Steps:
     - Factor: x² + 5x + 6 = (x + 2)(x + 3).
     - Divide: (x + 2)(x + 3) ÷ (x + 2) = x + 3.
   - Answer: x + 3

6. **[Medium] Vectors — Adding Vectors**
   - EN: Vector **u** = (3, 4) and vector **v** = (−1, 2). What is **u** + **v**?
   - FR: Le vecteur **u** = (3, 4) et le vecteur **v** = (−1, 2). Combien font **u** + **v**?
   - Choices: A) (1, 6)  B) (2, 6)  C) (4, 2)  D) (2, 2)
   - Hint: Add corresponding components: (a, b) + (c, d) = (a + c, b + d) (e.g., (5, 3) + (−2, 4) = (3, 7)).
   - Steps:
     - x-component: 3 + (−1) = 2.
     - y-component: 4 + 2 = 6.
     - **u** + **v** = (2, 6).
   - Answer: (2, 6)

7. **[Medium] Rate of Change — Derivative**
   - EN: Find the instantaneous rate of change of f(x) = 4x² − 3x at x = 2.
   - FR: Trouve le taux de variation instantané de f(x) = 4x² − 3x en x = 2.
   - Choices: A) 10  B) 13  C) 16  D) 19
   - Hint: Differentiate using the power rule, then substitute the x-value (e.g., f(x) = 3x² + 2x: f'(x) = 6x + 2; at x = 1, f'(1) = 8).
   - Steps:
     - f'(x) = 8x − 3 (using the power rule).
     - f'(2) = 8(2) − 3 = 16 − 3 = 13.
   - Answer: 13

8. **[Medium] Rational Function — Domain**
   - EN: What is the domain of f(x) = 5 / (x − 4)?
   - FR: Quel est le domaine de f(x) = 5 / (x − 4)?
   - Choices: A) All real numbers except x = 0  B) All real numbers except x = 4  C) All real numbers except x = 5  D) All positive real numbers
   - Hint: A rational function is undefined where the denominator equals zero — exclude that value from the domain (e.g., f(x) = 3/(x − 7): domain is all real numbers except x = 7).
   - Steps:
     - Set denominator equal to zero: x − 4 = 0, so x = 4.
     - The function is undefined at x = 4.
     - Domain: all real numbers except x = 4.
   - Answer: All real numbers except x = 4

9. **[Hard] Probability Distribution — Expected Value**
   - EN: A game pays $8 if you roll a 6 on a die and −$2 for any other result. What is the expected value per roll?
   - FR: Un jeu rapporte 8 $ si tu obtiens un 6 avec un dé et −2 $ pour tout autre résultat. Quelle est l'espérance mathématique par lancer?
   - Choices: A) −$0.67  B) $0.00  C) $0.67  D) $1.00
   - Hint: Expected value = Σ(outcome × probability) (e.g., win $10 with probability 1/6, lose $2 with probability 5/6: E = 10/6 − 10/6 = 0).
   - Steps:
     - P(rolling 6) = 1/6; outcome = +$8.
     - P(not rolling 6) = 5/6; outcome = −$2.
     - E = (1/6)(8) + (5/6)(−2) = 8/6 − 10/6 = −2/6 ≈ −$0.33.
     - Recalculate: 8/6 = 1.333, 10/6 = 1.667, E = 1.333 − 1.667 = −$0.33... Closest choice is −$0.67.
     - Actually: E = (8)(1/6) + (−2)(5/6) = 8/6 − 10/6 = −2/6 = −1/3 ≈ −$0.33. The closest and most accurate answer among the choices is −$0.67.

   *[Correction note: The exact answer is −$1/3 ≈ −$0.33. Adjusting the choices to make one correct.]*

   - Choices: A) −$1.00  B) −$0.33  C) $0.33  D) $1.33
   - Steps:

   - Answer: −$0.33
