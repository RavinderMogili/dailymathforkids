    • Hint: Add corresponding components.
    • Steps:
      • Add x-components, then y-components.
    • Answer: ( \langle4, -2\rangle ) B) ( \langle4, -1\rangle ) C) ( \langle4, -6\rangle ) D) ( \langle3, -2\rangle )

    • EN: If ( f(x) = x^2 + 2x ), find f'(x).

    • Steps:
