    • FR: La fonction de profit d'une entreprise est P(x) = −2x² + 40x − 50, où x est le nombre d'articles vendus. Combien d'articles maximisent le profit?
    • Choices: A) x = 8 B) x = 10 C) x = 12 D) x = 20
    • Hint: Find the derivative, set it equal to zero, and solve for x (e.g., P(x) = −3x² + 12x → P'(x) = −6x + 12 = 0 → x = 2).
    • Steps:
      • P'(x) = −4x + 40.
      • Set equal to zero: −4x + 40 = 0.
      • 4x = 40 → x = 10.
      • So 10 items maximize the profit.
    • Answer: x = 10
